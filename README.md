# ShowroomOS — Vehicle Management Demo

An interactive showroom inventory management portfolio demo by **Zanyar Muhammad**.

## Features
- Dashboard with vehicle count, availability, reservations, and inventory value
- Add, edit, and delete vehicle records
- Search by make, model, or year
- Filter by availability status
- Sort by price or newest entry
- Browser local storage persistence
- Responsive layout for mobile and desktop

## Tech stack
HTML, CSS, JavaScript (no external libraries).

## Run locally
Open `index.html` in a modern web browser.

## Publish with GitHub Pages
1. Create a public GitHub repository named `showroom-management-system`.
2. Upload `index.html` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. After GitHub Pages finishes publishing, your site URL should be:
   `https://YOUR-GITHUB-USERNAME.github.io/showroom-management-system/`

## Note
This is a browser-based portfolio demonstration built with HTML, CSS, and JavaScript. It is a separate web demo and should not be described as the C# Windows Forms implementation listed separately in the CV.
